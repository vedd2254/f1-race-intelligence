# F1 Race Intelligence

A Formula 1 analytics project exploring driver performance, championship standings, team statistics, and race reliability through interactive Tableau dashboards.

**[Live Demo](https://f1-race-intelligence-oufa.onrender.com)** · **[Tableau Dashboard](https://public.tableau.com/app/profile/ved.kashyap/viz/F1raceproject_17932230204200/Dashboard2)**  · **[Demo Video](https://cap.scourtfx.info/s/n2qxzm385qpjgd5)**

## Stack

`Python` · `Flask` · `pandas` · `Tableau` · `HTML/CSS/JavaScript`

## Run Locally

```bash
git clone YOUR_REPOSITORY_URL
cd f1-race-intelligence
pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5000`.
